# Todoist タスク登録

音声入力で頼まれることが多いので、まず表記を直してから登録する。

## 1. 内容を読み取る
依頼から次の3つを取り出す。
- 現場名
- やること（タスクの中身）
- 期日（言われたときだけ。言われていなければ付けない）

複数のタスクがまとめて言われたら、1件ずつに分ける。

## 2. 表記を直す
音声入力のため、漢字や表記がずれることがある。
- 現場名：既存のプロジェクト名に合わせる（例：「Lシティ」→ エルシティ）。
- 地名：実在の地名に合わせる（例：「西尾井」→ 西大井）。
- 取引先：
  - 新明電材（しんめいでんざい）：「新名電材」「新明ぜんざい」などは新明電材に直す。

どれのことか曖昧なときは、登録する前にユーザーに確認する。

## 3. プロジェクトを探す
- `find-projects` で「アノード」の下にある現場プロジェクトを探す。
- 見つからないときは、勝手に作らずにユーザーに確認する。

## 4. セクションを決める
`find-sections` でそのプロジェクトのセクションを取得する。

| 内容 | セクション |
|---|---|
| 材料の発注 | 発注物関係 |
| それ以外の新しいタスク | 未着手 |
| 着手したもの | 種類ごと（⭐︎図面関係⭐︎ / 工事/日程関係 / 発注物関係 / 連絡関係） |
| 返事待ち | 応答待ち |
| 終わったもの | 完了 |

## 5. 登録する
- タスク名は「現場名 + やること」にする（Todoist のプロジェクト名と同じ表記）。
  - 例：「エルシティ大井町 スラブ材料発注」「ER高田馬場計画 PE管104 管口保護材発注」
- 複数あるときは `add-tasks` でまとめて登録する。

## 6. 既存タスクの移動・完了
- 「応答待ちにして」「終わった」などは、`find-tasks` で該当タスクを探してから、`update-tasks` でセクションを移す。
- 終わったタスクは、完了にせず「完了」セクションに移す。
- 該当するタスクが複数あるときは、どれか確認する。

## 7. 報告する
登録・移動したタスクを、プロジェクト名・セクション・タスク名で短く伝える。表記を直したところがあれば、それも伝える。
