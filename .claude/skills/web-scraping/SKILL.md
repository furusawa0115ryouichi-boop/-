# Webスクレイピング

## 1. 何を集めるか確認する
次の4つがはっきりしていなければ、始める前に聞く。
- どのサイト・ページか（URL）
- 何の情報か（例：品番・品名・価格・在庫）
- どのくらいの量か（1ページだけか、一覧の全ページか）
- 結果の形（チャットで表 / Excel / CSV）。言われなければ、少ないならチャットで表、多いなら Excel にする。

## 2. やってよいか確認する
- そのサイトの `robots.txt` と利用規約で、自動での取得が禁止されていないか見る。禁止なら、やらずにユーザーに伝える。
- ログインが必要なページは、IDやパスワードを聞いてまで取りにいかない。ユーザーに方法を相談する。
- アクセスは間隔をあける（1ページごとに1秒以上）。同時に大量に取りにいかない。

## 3. やり方を選ぶ

| 状況 | やり方 |
|---|---|
| 数ページだけ | `WebFetch` でページを読み、必要な情報を抜き出す |
| 一覧が何ページもある・決まった形で大量に集める | Python（`requests` + `BeautifulSoup`）でプログラムを書いて動かす |
| JavaScript で表示されるページ（WebFetchで中身が空） | Playwright（Chromium は `/opt/pw-browsers/chromium`）を使う。入っていなければ `pip install playwright` で入れる（ブラウザのダウンロードはしない） |
| ログインが必要・ユーザーのブラウザで見る必要がある | `chrome-browser` か `built-in-browser` のスキルを使う（パソコンとの接続が必要） |

## 4. プログラムで集めるとき
- プログラムはスクラッチパッドに置く（リポジトリには入れない）。
- 取ってきたHTMLもスクラッチパッドの専用フォルダに保存し、Python は `-I` を付けて動かす。
- 最初に1ページだけ試し、正しく取れているかユーザーに見せてから全ページに広げる。
- `User-Agent` を付け、エラーのときは少し待って再試行する（最大3回）。
- 取れなかったページは飛ばさずに記録し、最後に報告する。

## 5. 整える
- 列名は日本語にする（例：品番 / 品名 / 価格 / URL）。
- 価格は数字にそろえる（「¥1,200（税込）」→ 1200、税込か税抜かは列名に書く）。
- 重複は消す。元のページのURLを列に残す。
- Excel にするときは `xlsx` スキルの手順に従う。

## 6. 報告する
- 何件取れたか、どのページから取ったか、取れなかったものがあればその理由を短く伝える。
- ファイルを作ったときは、`SendUserFile` で渡す。
- 取ってきた内容を Todoist に入れるときは `todoist-task` スキルに従う。
